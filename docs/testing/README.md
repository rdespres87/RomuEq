# Testing Strategy

## Unit tests

DSP mathematics, parameter validation and state migrations.

## Property tests

Parameter ranges, arbitrary block sizes and automation sequences.

## Concurrency tests

Model checking and stress tests for producer/consumer protocols.

## Real-time tests

Allocation tracking and forbidden-operation checks.

## Reference audio

Impulse, silence, sine, noise and full-scale fixtures.

## Integration tests

Plugin lifecycle, state, automation and host compatibility.
