- Windows x64
- Linux x64

- REAPER

## Validation dimensions

- plugin scan;
- instantiate;
- GUI creation;
- automation;
- state save/reload;
- preset handling;
- bypass;
- sample-rate changes;
- block-size changes;
- offline rendering;
- multiple instances.
