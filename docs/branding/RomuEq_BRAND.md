# RomuEq Brand

## Brand name

**RomuEq**

> **Status: PROVISIONAL / NOT CLEARED.** This is a working product name
> pending formal trademark and domain clearance.

## Positioning

**Precision Audio Processing**

RomuEq is the working brand for a professional audio-processing platform.
The initial product is **RomuEq EQ**, with room for future audio tools.

## Product family

- RomuEq EQ
- RomuEq Analyzer
- RomuEq Dynamics
- RomuEq Limiter
- RomuEq Suite

## Visual direction

- Dark, high-contrast professional audio interface
- Electric violet primary accent
- Cyan technical accent
- Neutral near-black surfaces
- Clean geometric typography
- Distinctive Q-shaped mark
- Subtle waveform / spectrum motifs

## Naming rationale

"Romu" provides the personal signature. "Q" is a subtle reference to the
Q factor used in parametric equalization.

## Tagline

**Precision Audio Processing**

## Alternative messaging

- Precision. Sound. Control.
- Hear Every Detail.
- Sculpt Sound with Precision.
- Engineered for the Sound You Imagine.
- Pure Processing. Total Control.

## Clearance status

A preliminary web screening found no obvious audio-plugin or audio-software
product using the exact `RomuEq` casing. However, the underlying string
`RomuEq` is already used by a municipal public-security patrol in Queimados,
Brazil. This is a real-name collision even though the field is unrelated to
audio software.

Therefore **RomuEq must not yet be described as 99% cleared**.
