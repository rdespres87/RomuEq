# RomuEq Name Clearance — Preliminary Report

**Date:** 2026-09-01  
**Status:** PRELIMINARY — NOT LEGAL CLEARANCE  
**Decision:** **NO-GO for a 99% confidence claim**

## Executive summary

The proposed display name is **RomuEq**.

The web screening did not reveal an obvious audio plugin, DAW tool or audio
software product using the exact spelling `RomuEq`. However, the exact
underlying string `RomuEq` is already used in Brazil as the name of a
municipal public-security patrol.

The Câmara Municipal de Queimados publishes Law 1,418/2017 identifying the
group as **RomuEq** (Ronda Municipal de Queimados). Its official legislative
index also lists the law under RomuEq.

This does not automatically prevent use of RomuEq for audio software, but it
means the name cannot honestly be described as unused or 99% clear.

## Web findings

- **Confirmed collision:** `RomuEq` is an existing municipal public-security
  organization in Queimados, Rio de Janeiro, Brazil.
- **Audio/software:** no obvious exact-name collision found in the current
  web screening.
- **General web:** the lowercase string `romuq` also appears as a NameMC
  profile; this is not an audio/software collision.
- **Trademark databases:** the web search did not produce sufficient
  authoritative registry evidence to declare clearance.
