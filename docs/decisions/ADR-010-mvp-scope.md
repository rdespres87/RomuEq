# ADR-010: MVP scope

Status: Accepted

## Included

8-band minimum-phase EQ, mono/stereo, parameters, automation, meters, analysis, presets/state, CLI/offline renderer, and CLAP/VST3 adapters after validation.

## Excluded

Dynamic EQ, linear phase, oversampling, Mid/Side, WASM, AUv3, multichannel, sidechain, and advanced modulation.
