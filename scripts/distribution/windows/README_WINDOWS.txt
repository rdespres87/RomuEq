================================================================================
 EQUAFORM-8 DAW PLUGINS — WINDOWS BETA TESTER QUICKSTART
================================================================================

Thank you for testing Equaform-8 on Windows!

SYSTEM REQUIREMENTS:
--------------------
- Windows 10 (version 1809 or newer) or Windows 11 (64-bit only).
- DirectX 12, Vulkan, or Direct3D 11 compatible GPU with updated display drivers.
- 64-bit DAW host supporting VST3 or CLAP.

QUICK INSTALLATION:
-------------------
1. Run "Equaform-8-Plugins-Windows-v1.0.0.exe".
2. Select your desired formats (VST3, CLAP, and Factory Presets).
3. Complete the setup wizard (administrator privileges required).
4. Launch your DAW (Ableton Live, Cubase, Studio One, Bitwig, Reaper, FL Studio).
5. Load "Equaform-8" on an audio or instrument track!

INSTALLED LOCATIONS:
--------------------
- VST3 Plugin      : C:\Program Files\Common Files\VST3\Equaform-8.vst3\
- CLAP Plugin      : C:\Program Files\Common Files\CLAP\Equaform-8.clap
- System Presets   : C:\ProgramData\Equaform\presets\
- User Presets     : %APPDATA%\Equaform\presets\

UNINSTALLATION:
---------------
To cleanly uninstall Equaform-8, open "Windows Settings" > "Apps" > "Installed apps",
find "Equaform-8 DAW Plugins" and click "Uninstall".
Your custom user presets in %APPDATA%\Equaform\presets\ will be safely preserved.
