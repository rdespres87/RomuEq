================================================================================
 EQUAFORM-8 DAW PLUGINS — BETA TESTER QUICKSTART
================================================================================

Thank you for testing Equaform-8!

REQUIREMENTS:
-------------
- Apple Silicon Mac (M1/M2/M3/M4)
- macOS 12.0 Monterey or later

QUICK INSTALLATION:
-------------------
1. Double-click "Equaform-8-Plugins-Installer.pkg".
2. If macOS displays a Gatekeeper warning:
   - On macOS 13/14: Right-click (or Control+click) the .pkg and select "Open".
   - On macOS 15 (Sequoia): Open System Settings > Privacy & Security,
     scroll to Security, and click "Open Anyway".
   - Alternatively: Double-click "Open-Installer-Gatekeeper.command" right here.
3. Follow the installer instructions (administrator password required).
4. Launch your DAW (Logic Pro, Ableton Live, Bitwig, Reaper, Cubase).
5. Load "Equaform-8" on an audio or instrument track!

WHAT'S INCLUDED:
----------------
- Audio Unit v2 (AUv2)  : /Library/Audio/Plug-Ins/Components/Equaform-8.component
- VST3                  : /Library/Audio/Plug-Ins/VST3/Equaform-8.vst3
- CLAP                  : /Library/Audio/Plug-Ins/CLAP/Equaform-8.clap
- 15 Factory Presets    : ~/.equaform/presets/ & /Library/Application Support/Equaform/presets/

MANUAL INSTALLATION OPTION:
---------------------------
If you prefer not to use administrator privileges, explore the "Manual-Install"
folder and run "install-user-plugins.command" to install directly to ~/Library/.

NEED HELP OR WANT TO REPORT FEEDBACK?
-------------------------------------
Please read "TEST_GUIDE_MAC.md" for full DAW scan instructions, troubleshooting,
and our structured feedback checklist.
