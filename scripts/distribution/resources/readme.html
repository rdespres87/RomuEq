Requirements & Compatibility

This beta build runs natively on macOS 12.0 or newer for Apple Silicon (M1/M2/M3/M4).

  • Apple Logic Pro & GarageBand: Audio Unit (AUv2)
  • Ableton Live: VST3 and AUv2
  • Bitwig Studio: Native CLAP and VST3
  • Cockos Reaper: CLAP, VST3, and AUv2
  • Steinberg Cubase / Nuendo: VST3
  • Studio One & FL Studio: VST3 and CLAP

Automatic Post-Install Configuration

The installer automatically performs the following setup tasks:

  • Cleans macOS quarantine flags (Gatekeeper) from all installed plugins.
  • Refreshes the CoreAudio plugin registrar for immediate detection in Logic Pro.
  • Deploys 15 factory presets into your user presets folder.
